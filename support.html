サポート

TrainingApp をご利用いただきありがとうございます。不具合の報告・機能要望・ご質問は、以下いずれかの方法でご連絡ください。

メールで問い合わせる

一般的なお問い合わせはメールで受け付けています。

maru_sc15@icloud.com

GitHub Issues で報告する

不具合の報告や機能要望は GitHub Issues でも受け付けています (公開されます)。

https://github.com/example/train-landing/issues

フォームで送信する (任意)

Google Form でも受け付けています。メールを開けない環境の方はこちらをご利用ください。

Google Form (URL 未設定)

対応方針

  • 個人開発のためベストエフォートでの対応となります。返信までに数日いただく場合があります。
  • 返信・問題解決・機能追加を保証するものではありません。
  • 緊急性の高い障害 (アプリが起動しない等) は GitHub Issues またはメールのタイトルに「【緊急】」と記載いただけるとスムーズです。
  • 医療・トレーニング指導に関する個別相談にはお答えできません。

よくある質問

多くのご質問は トップページの FAQ に回答があります。お問い合わせ前にご一読ください。
