主な機能

AI でプログラム生成

目的・経験・機材に応じたプロンプトテンプレートを提供。ChatGPT / Claude に貼り付けて生成した JSON をアプリに取り込みます。

HealthKit 連携

歩数・心拍・ランニング / ウォーキングのワークアウトを読み取り、筋トレ以外の活動も一覧で把握できます。

完全ローカル動作

アカウント登録不要、サーバー通信なし、広告なし。記録はすべて端末内のみに保存されます。

ミニマル UI

ダークモード固定。トレーニング中に迷わないよう、必要な情報だけを大きく表示します。

進捗の可視化

12週間の達成度・挙上重量推移・週次ボリュームをシンプルなチャートで確認できます。

プロ仕様のログ

セット毎の重量・回数・RPE を素早く入力。前回比の差分をその場で確認しながら追い込めます。

画面イメージ

実機スクリーンショット。タップで拡大 (予定)。

よくある質問

無料で使えますか？

現時点では無料を予定しています。アプリ内課金・サブスクリプションの導入予定はありません。

アカウント登録は必要ですか？

不要です。メールアドレスや氏名などの個人情報は一切求めません。インストール直後からすぐに使い始められます。

データはどこに保存されますか？

すべて端末内にローカル保存されます。サーバーへの送信は行いません。iCloud バックアップ経由でのみ Apple のインフラに保存されます。

プログラム JSON とは？

12週間分の種目・セット数・目標重量などを構造化した JSON ファイルです。アプリが提供するプロンプトを ChatGPT / Claude に貼り付けると生成でき、それを読み込むとプログラムとして実行可能になります。

対応 OS は？

iOS 16 以降の iPhone を想定しています。iPad / Mac / Apple Watch 対応は今後検討予定です。

未成年でも使えますか？

自己責任での利用を前提とします。高重量を扱うトレーニングは成長期の身体に影響する可能性があるため、18歳未満の方は保護者・専門家の指導のもとで使用してください。
