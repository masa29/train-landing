第1条 (前文および事業者情報)

masa (以下「運営者」といいます) は、iOS アプリケーション TrainingApp (以下「本アプリ」といいます) における利用者の個人情報およびそれに準ずる情報 (以下総称して「利用者情報」といいます) の取扱いについて、本プライバシーポリシー (以下「本ポリシー」といいます) を定めます。本アプリを利用する利用者は、本ポリシーに記載された内容を理解したうえで本アプリを利用するものとします。

第2条 (本アプリの設計方針)

本アプリは、次の設計方針に基づいて構築されています。本ポリシーを読むうえで前提となるため、最初に明示します。

  1. サーバーを持たない: 本アプリは運営者のサーバーと一切通信しません。
  2. アカウント登録なし: 氏名、メールアドレス、電話番号等による利用者の登録は行いません。
  3. ネットワーク権限を要求しない: 本アプリは iOS のネットワーク権限を要求しません。
  4. 完全ローカル動作: すべてのデータは利用者の端末内にのみ保存されます。

第3条 (取得する情報)

本アプリは、次の情報を取得し、端末内でのみ処理します。

3.1 Apple HealthKit から読み取る情報

利用者が明示的に許可した場合に限り、本アプリは Apple HealthKit から次の情報を読み取ります。書き込みは一切行いません。

  • 歩数
  • 心拍数
  • ワークアウト情報 (種目、開始・終了時刻、時間等)
  • 距離 (ランニング、ウォーキング等)
  • ペース (ランニング)
  • ケイデンス (ランニング)
  • 消費カロリー (アクティブ、基礎代謝)
  • その他、利用者が HealthKit の権限画面で許可したランニング関連の指標

HealthKit へのアクセスは iOS の権限設定画面からいつでも取り消すことができます。

3.2 利用者が入力する情報

利用者が本アプリに対して自ら入力または取り込んだ次の情報を、端末内に保存します。

  • ワークアウト記録 (種目、セット数、重量、反復回数、RPE、メモ等)
  • 外部の大規模言語モデル (ChatGPT、Claude 等) から取得し、利用者が本アプリに取り込んだトレーニングプログラムの JSON データ
  • プログラムの進捗状況、週次・日次の完了状態

3.3 端末に保存される設定情報

本アプリの動作に必要な次の情報を、SwiftData および UserDefaults を用いて端末内に保存します。

  • アプリ内の各種設定 (表示単位、通知設定等)
  • 本規約および本ポリシーへの同意状態、同意したバージョン番号
  • 最後に起動した日時等、アプリの挙動に関する最小限の状態情報

第4条 (取得しない情報)

本アプリは、次の情報を一切取得しません。この点は本アプリの重要な設計方針です。

  • 氏名、ふりがな、生年月日
  • メールアドレス、電話番号
  • 住所、郵便番号
  • 位置情報 (GPS、Wi-Fi、基地局、その他いかなる方法によるものも含む)
  • 連絡先 (アドレス帳)
  • 写真、カメラ、マイク
  • 広告識別子 (IDFA)、Identifier for Vendors (IDFV) を用いた識別行為
  • その他、利用者個人を運営者が特定しうる情報

第5条 (データの保存場所)

本アプリが取得または生成するすべての情報は、利用者の端末内にのみ保存されます。運営者のサーバー、クラウドストレージ、第三者のサービス等への送信は一切行いません。iCloud 同期は、利用者が iOS の設定で有効化している場合に限り、Apple が提供する仕組みに従って行われることがあります。この場合、iCloud 上のデータは Apple のプライバシーポリシーに従って取り扱われます。

第6条 (第三者提供)

運営者は、利用者情報を第三者に提供しません。本アプリは運営者のサーバーと通信しないため、構造上、運営者が利用者情報を取得または提供することはできません。

第7条 (外部サービスとの関係)

7.1 本アプリ内での外部サービス利用

本アプリは、その機能の範囲内において、解析ツール、広告ネットワーク、クラッシュレポート収集サービス等の外部サービスを利用しません。

7.2 利用者による外部 LLM の利用

本アプリに取り込むトレーニングプログラムの JSON は、利用者が自らの責任において ChatGPT、Claude 等の外部の大規模言語モデルサービスを利用して生成するものです。これらのサービスの利用は、各サービスの提供者と利用者との間の契約に基づくものであり、運営者は関与しません。外部 LLM サービスにおけるプロンプトおよび応答の取扱いは、各サービスのプライバシーポリシーが適用されます。利用者は、外部 LLM に入力する情報に個人情報や機微情報が含まれないよう自ら注意する責任を負います。

第8条 (Apple HealthKit データの取扱い)

本アプリにおける HealthKit データの取扱いは、Apple 社が定める HealthKit に関するガイドラインに準拠します。具体的には次のとおりです。

8.1 利用目的の限定

HealthKit から読み取ったデータは、本アプリ内におけるトレーニングの記録、可視化、進捗管理の目的にのみ使用します。

8.2 広告およびマーケティング利用の禁止

HealthKit から取得したデータを、広告の配信、マーケティング、利用者プロファイリング、その他類似の目的に使用することはありません。

8.3 第三者提供の禁止

HealthKit から取得したデータを、利用者の明示的な同意なく第三者に提供することはありません。本アプリは通信機能を持たないため、構造上、第三者提供は発生しません。

8.4 暗号化

HealthKit データの暗号化は iOS の仕組みに従って行われます。端末のパスコード設定およびデバイス暗号化を有効にすることを推奨します。

8.5 権限の取消し

利用者はいつでも、iOS の「設定」アプリの「プライバシーとセキュリティ」内の「ヘルスケア」から、本アプリに付与した HealthKit の権限を個別に取り消すことができます。

第9条 (利用者の権利)

9.1 データの削除

利用者は、本アプリを端末からアンインストールすることにより、本アプリが端末内に保存したすべてのデータを削除することができます。アンインストール後、運営者が当該データを保持することはありません (そもそも運営者は当該データを保有していません)。

9.2 個別削除

利用者は、本アプリ内の機能を通じて、ワークアウト記録、取り込んだプログラム、設定等を個別に削除することができます。

9.3 データのエクスポート

利用者は、本アプリが提供する機能の範囲内で、自身のデータをエクスポートすることができます。エクスポート機能の詳細は本アプリ内の説明に従います。

9.4 HealthKit データへの影響

本アプリから HealthKit の権限を取り消した場合、または本アプリをアンインストールした場合でも、HealthKit 本体に保存されている利用者のデータ (歩数、心拍等) には影響しません。HealthKit データそのものの管理は Apple のヘルスケアアプリを通じて行われます。

第10条 (Cookie およびトラッキング)

本アプリは、Cookie、ウェブビーコン、その他類似の技術を用いた利用者のトラッキングを行いません。iOS の App Tracking Transparency (ATT) フレームワークに基づく追跡許可ダイアログも、本アプリは表示しません。

第11条 (18歳未満の取扱い)

11.1 対象年齢

本アプリは、トレーニングを行う成人 (18歳以上) を主な対象としています。

11.2 未成年者の利用

18歳未満の者が本アプリを利用する場合、保護者 (親権者または法定代理人) の同意および監督のもとで行うものとします。保護者は、本アプリの内容、トレーニングの安全性、本ポリシーの内容を十分に理解したうえで、未成年者の利用を許可する責任を負います。

11.3 年齢確認

本アプリはアカウント登録を行わないため、利用者の年齢を技術的に確認する手段を有しません。運営者は、利用者が自ら適切な年齢であることを前提として本アプリを提供します。

第12条 (本ポリシーの変更)

12.1 変更の方法

運営者は、法令の変更、本アプリの機能変更、その他の事情により、本ポリシーを変更することがあります。変更後のポリシーは、本アプリ内での通知または運営者が指定する方法による告知の時点から効力を生じます。

12.2 バージョン管理

本ポリシーは、先頭に記載されたバージョン番号および発効日により管理されます。重要な変更が行われた場合、利用者は本アプリの次回起動時等に改訂版への同意を求められることがあります。

12.3 軽微な変更

表現の明確化や誤字脱字の修正等、利用者の権利義務に実質的な影響を及ぼさない変更については、バージョン番号を上げずに随時行うことがあります。
